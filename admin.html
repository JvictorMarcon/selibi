Quase lá

Você entrou, mas sua conta ainda não é administradora do blog. No Supabase, abra o SQL Editor e rode:

insert into public.admins (user_id) values ('');

Depois, recarregue esta página.

Painel do blog

Novo texto

Aparece no card do blog e no topo do texto.

Deixe uma linha em branco entre parágrafos. Use ## para subtítulo, > para citação, - para lista, **negrito**, *itálico* e [texto](https://link).

JPG, PNG ou WebP até 5 MB. Use só imagens que a escola tem direito de usar.
